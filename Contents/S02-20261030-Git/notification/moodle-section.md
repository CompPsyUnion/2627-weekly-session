Part 1: From Saving Files to Building History

In this part, Siyuan will start from the question "why do we need version control?" and guide everyone through the basic workflow — staging, committing, and reading history — entirely in the VS Code Source Control view.

He will also take a look under the hood at snapshots, hashes, and the commit graph, so that you understand what Git actually saves each time you commit.

Part 2: From Branches to Distributed Collaboration

Are you afraid of breaking your project when trying something new? Do you wonder what a "branch" really is, or what push, fetch, and pull actually do?

In this part, Siyuan will explain what branches are, how merging and conflicts work, how to undo a wrong commit, and how Git and GitHub work together in distributed collaboration.
