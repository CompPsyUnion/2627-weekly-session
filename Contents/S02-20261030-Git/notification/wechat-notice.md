Part 01:

在这个部分的分享中，我将从“为什么需要版本控制”这个问题出发，带着大家看看 Git 到底帮我们解决了什么。

你的文件夹里是不是也有过 `main.py`、`main_old.py`、`main_final.py`、`main_final_really_final.py`？想回到三天前那个能跑的版本，却发现怎么也找不回来了？

这次我们不背命令，全程用 VSCode 的图形界面演示：暂存、提交、查看历史。还会带大家看看每次点击“提交”之后，Git 底层到底保存了什么 —— 快照、哈希、提交图，全都安排上[旺柴]

Part 02:

你是否也遇到过这样的场景。

- 想试试新算法，又怕把现在能跑的版本改崩，只好把整个项目复制一份当备份？
- 听大佬们说“开个分支就行”，自己却不知道分支到底是什么？
- push / pull 一报错就一头雾水，不知道 Git 想说什么？

在这个部分，我会讲清楚分支为什么轻量、合并怎么发生、冲突为什么不可怕、怎么撤销一次错误的提交，以及 Git 和 GitHub 到底是什么关系 —— push、fetch、pull 各自在移动什么。全程依然用简单的 VSCode 图形界面来给大家演示。
