Part 1: GitHub Beyond the Code — From a Fork to Your First Merged PR

Have you ever wondered how you could safely contribute your changes to a project like our weekly session repo, or even big projects like VS Code, whose authors you have never met? And why do people keep chasing those green squares on their profiles?

In this part, Siyuan He (Robert) will walk everyone through the standard workflow of open-source collaboration — entirely in the browser, with no installation and no command line. You will file a real Issue, fork a repository and create a branch, open your very first Pull Request, watch GitHub Actions (a robot colleague) check your changes automatically, and publish the repository as a live website with GitHub Pages.

By the end of the session, everyone will have a merged pull request — and a fresh green square on their profile.
