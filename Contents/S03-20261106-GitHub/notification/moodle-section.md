Part 1: GitHub Beyond the Code — From a Fork to Your First Merged PR

In this part, Siyuan will guide everyone through a complete open-source contribution, entirely in the web browser: recording a problem in an Issue, forking the repository and creating a branch, opening and reviewing a Pull Request, reading the automated checks run by GitHub Actions, and publishing the repository as a live website with GitHub Pages.

No installation and no command line are required. Everyone may leave with a merged pull request.
