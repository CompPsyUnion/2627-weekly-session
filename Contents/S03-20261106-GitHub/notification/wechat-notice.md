Part 01:

在这个部分的分享中，何思源（Robert）将带大家真正“住进” GitHub —— 像全世界的开源开发者一样在上面协作。

你有没有想过：你不认识 VS Code 的作者，怎么安全地把你的修改贡献给它？为什么总有人在拼命刷主页上的绿格子？

这次全程只用浏览器、零安装零命令行：提一个真实的 Issue，Fork 仓库、开一条自己的分支，发出你的第一个 Pull Request，看机器人同事（Actions）替你把代码检查一遍，再用 GitHub Pages 把仓库一键变成能访问的网站——下课前，每个人都会拿到自己的一个 merged PR，把主页的绿格子点亮 💡

无论你是完全没碰过 GitHub 的新手，还是已经用过它存代码的同学，都欢迎来玩！
